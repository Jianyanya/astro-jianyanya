# 铃月检索回归集

60 组：dev 36 / holdout 24；50 个正例（含 2 个跨文事实问题）、10 个无答案问题。
每个正例有简短标准答案、文章 ID 与原文证据；标签由助手整理，待作者逐条人工复核。
集中覆盖六篇技术/设计文章，不能据此推断全博客或真实访客准确率。

```sh
pnpm generate:knowledge
pnpm knowledge:evaluate --split=dev
# 固定代码与参数，再跑留出集；不要依据留出成绩反复调参
pnpm knowledge:evaluate --split=holdout
```

评测使用本机临时 PostgreSQL/pgvector 和真实 Embedding/Reranker 调用；不连接线上数据库，
不生成聊天回答。默认 `.cache/lingyue/prepared.json` 必须与当前切分对应，旧产物需重新生成。
模型响应、向量和详细报告都在 Git 忽略的 `.cache/lingyue/`，相同模型请求缓存复用。
请顺序运行评测，避免并发写同一份缓存。新调用仍按服务商规则计费。

可选 `--label=名称`、`--prepared=相对或绝对文件路径`、`--chunks=已保存片段JSON`。
`--policy=legacy` 重放原来的 6 段/6,500 字节证据预算；用于和保存的旧片段及向量比较。
先保存旧版切分生成的片段、快照和向量，再修改切分；仅拿旧向量配新版片段无法公平比较。

报告包含关键词@10、RRF@20、重排@6、最终证据@6 的事实级 Recall、MRR、片段级 nDCG。
还区分完全无关和同话题缺事实的证据接纳率；这项不是回答幻觉率。
标题和章节会作为上下文发给模型，因此也参与证据命中判断。
每个标准答案目前供人工核对，本脚本不判定模型最终回答正确性。

标签失效（原文已改/删）时脚本终止，要求审阅标签；不要把已失效样本静默跳过来抬高成绩。
当前措辞只检查原句级证据：真实语义等价但没有标注原句的片段可能被低估。
更新题集时保留旧报告和 datasetHash，不能直接与另一版题集混比。

本轮结果见 [RESULTS.md](./RESULTS.md)，设计与限制见
[RAG 实现说明](../../docs/features/lingyue-rag.md)。
