### 1. [1518. 换水问题](https://leetcode.cn/problems/water-bottles/)
**最终代码：

```cpp
int numWaterBottles(int numBottles, int numExchange) {

        int ans = numBottles;

        int t = 0;

        while(numBottles>=numExchange){

            t = numBottles%numExchange;

            numBottles /= numExchange;

            ans += numBottles;

            numBottles += t;

        }

        return ans;

    }
```
