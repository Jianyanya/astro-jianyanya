## 今日学习记录
### 1. [Problem-493C-cf](https://codeforces.com/problemset/problem/493/C)
**关键词**：`模拟`
**问题分析**：
你可以自定义距离 d,给出两组数据代表两队 a 和 b 的投掷距离,大于 d 的得 3 分,反之 2 分,求如何定义 d,让 a 队得分-b 队得分的最大值

**核心思路**:
先假设 d 为 0,然后把 a 和 b 的距离混在一起进行排序,然后遍历数组,令`d=a[i]或者d=b[j]`,当遍历到最后或者遇到不同距离的时候再更新差值

**最终代码：

```cpp

#define fo(i,l,r) for(int i=(l);i<=(r);++i)

#define ve vector

#define endl '\n'

const int MOD=998244353;

int T;

int n,m;

void solve(){

    cin>>n;

    ve<pair<int,int>> arr;

    fo(i,1,n){

        int p;cin>>p;

        arr.emplace_back(p,0);

    }

    cin>>m;

    fo(i,1,m){

        int p;cin>>p;

        arr.emplace_back(p,1);

    }

    ranges::sort(arr);

    int a = 3*n,b = 3*m;

    int ansa = a,ansb = b;

    int diff = a-b;

    fo(i,0,arr.size()-1){

        int d = arr[i].second;

        if(d) b--;

        else a--;

        bool flge = false;

        if(i==arr.size()-1||arr[i].first!=arr[i+1].first) flge = true;

        if(flge){

            int newdif = a - b;

            if(newdif>diff) ansa = a,ansb = b,diff = newdif;

        }

    }

    cout<<ansa<<':'<<ansb;

}

signed main() {

    ios_base::sync_with_stdio(false);

    T = 1;

    while(T--) solve();

}
```
