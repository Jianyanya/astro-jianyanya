### 1. 包含所有 1 的最小矩形面积 I[leetcode.3195](https://leetcode.cn/problems/find-the-minimum-area-to-cover-all-ones-i?envType=daily-question&envId=2025-08-22)
**关键词**：`矩阵`
**问题分析**：
1. 给你一个二维 **二进制** 数组 `grid`。请你找出一个边在水平方向和竖直方向上、面积 **最小** 的矩形，并且满足 `grid` 中所有的 1 都在矩形的内部.返回这个矩形可能的 **最小** 面积。

**核心思路**
1. 没啥,就是记录矩阵 1 到达的最大的长宽和最小的位置
2. 可是我思考了半天都没想出来真的难受,我其实想的是真确的思路,但是没正确的实现

**最终代码：

```cpp
int minimumArea(vector<vector<int>>& grid) {

        int n = grid.size(),m = grid[0].size();

        int r = 0,l = INT_MAX,h = 0,b = INT_MAX;

        for(int i = 0;i<n;i++){

            for(int j = 0;j<m;j++){

                if(grid[i][j]){

                    r = max(r,j);

                    l = min(l,j);

                    h = max(h,i);

                    b = min(b,i);

                }

            }

        }

        return (r-l+1)*(h-b+1);

    }
```
