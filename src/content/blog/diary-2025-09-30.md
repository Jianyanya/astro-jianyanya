### 1. [2221. 数组的三角和](https://leetcode.cn/problems/find-triangular-sum-of-an-array/)
**最终代码：

```cpp
int triangularSum(vector<int>& nums) {

        for(int i = 0;i<nums.size();i++){

            for(int j = 0;j<nums.size()-i-1;j++){

                nums[j] = (nums[j]+nums[j+1])%10;

            }

        }

        return nums[0];

    }
```
