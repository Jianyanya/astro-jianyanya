### 1. [3100. 换水问题 II](https://leetcode.cn/problems/water-bottles-ii/)
**最终代码：

```cpp
int maxBottlesDrunk(int numBottles, int numExchange) {

        int empty = numBottles,ans = numBottles;

        while(empty>=numExchange){

            empty -= numExchange;

            numExchange++;

            ans++;

            empty++;

        }

        return ans;

    }
```
