 Astro 文章里嵌组件的正确姿势：把文章存成 **`.mdx`**，文件开头 import 组件，然后像写 HTML 一样使用它。

## 直接看效果

下面这个「数据与判定链路」就是 `src/components/demo/ArchFlow.astro` 组件渲染出来的——数据**全部来自你自习室占座系统的真实文档**（采集 App、复核队列、KNN+决策树双模型、权限分层），不是占位符。卡片入场动画、箭头弹跳、底部规则播报每 4 秒轮换：

import ArchFlow from '@components/demo/ArchFlow.astro';

<ArchFlow />

## 这个组件的解剖

一个 `.astro` 文件分三段，你贴的那个博客（`aoa-arch-*` 类名）就是这么写的：

**① 组件脚本（文件顶部 `---` 之间）**——纯 JS，构建时运行，适合放数据和逻辑：

```ts
const layers = [
  { kicker: '◎ 入口（薄）', title: '用户消息', sub: '...' },
  { kicker: '◎ 服务器（厚）', title: '队列 / 路由器', sub: '...' },
];
const { title } = Astro.props;   // 接收外部传参
```

**② 模板（中间）**——类 JSX 写法，支持 `{表达式}`、`.map()` 渲染列表：

```tsx
<section class="arch">
  {layers.map((layer, i) => (
    <div class="arch-card" style={`--i: ${i + 1}`}>{layer.title}</div>
  ))}
</section>
```

**③ 样式 + 脚本（文件底部）**——`<style>` 默认 **scoped**（只作用于本组件，Astro 自动加 `astro-xxx` 哈希类，这就是你在别人代码里看到 `astro-w2ujzu2z` 的原因）；`<script>` 会打包进客户端，实现轮播、点击等交互。

## 用它的一些建议

- 数据驱动：把卡片内容放进数组再 `.map()`，加一层卡片只是加一行数据
- `--i` CSS 变量做入场动画的阶梯延迟，比手写 animation-delay 优雅
- `aria-live="polite"` 让轮播内容对读屏软件友好（你贴的那段里也有）
- 组件放到 `src/components/` 下任何位置，路径别名 `@components/` 可用

## 想自己写一个？

复制 `src/components/demo/ArchFlow.astro` 改内容就是你的了。组件里的数据和文案全部在顶部脚本区，改起来不用碰样式。
